# まとあて大作戦！

**データで見つける、最強の作戦**

大砲からボールを発射し、統計的な意思決定を楽しむ日本語の静的HTMLゲーム。ゲーム・統計分析にビルドやサーバー側処理は不要です。アクセス記録のみ、既存の共用GASを利用します。

## 起動

```sh
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。ES Modulesを使うため、HTMLを直接ダブルクリックするのではなくHTTPで開いてください。

## GitHub Pages

このリポジトリのルートを公開できます。GitHubの Settings → Pages → Deploy from a branch で公開するブランチと `/ (root)` を選んでください。相対URLだけを使っているため、リポジトリ名付きURLにも対応しています。今回の作業ではコミット、push、公開操作は行っていません。

## 操作と機能

- 大砲と的を選択し、①スタート→②パワーを決める→③方向を決めるの3タップ。SPACEでも操作できます。
- 的は近距離60/40/20点、中距離100/60/20点、遠距離150/80/10点。広場の中5点、外まわり2点、場外0点。
- 4種類の大砲で飛距離、メーター速度、ランダムな着弾誤差が異なります。ロケット大砲は近距離でばらつきが大きくなります。
- 緑の「ここ！」が操作の目安。白い線が現在の値です。大砲の向きと点線が操作に合わせて動き、発射後はボールが弧を描いて飛びます。着弾後は得点と、パワー・方向が行き先にどう影響したかを表示します。
- 実験は5/10/20/30/50/100回、または1〜10000回。練習は無制限。
- 発射ごとに大砲と的を変更できます。飛行中や操作中は条件を固定します。
- 全発射はlocalStorageへ自動保存。新しい実験を始める際、既存の未保存実験も履歴へ保存します。結果画面で名前を付けて保存・上書きできます。
- 過去の実験は結果のセレクトから呼び出せます。保存実験を2〜4件選んで比較できます。
- 合計、平均、中央値、分散、標準偏差、最大、最小、0点率と試行回数を表示。
- ヒストグラム、得点推移、累積得点、場外を含む実座標散布図、大砲別・狙った的別の集計。
- 比較は度数・相対度数と累積平均グラフ。異なる試行回数でも平均・相対度数で検討できます。
- 通常CSVは、発射番号・大砲・狙った的・当たった的・得点・速度・日時の7列。実験名はファイル名に含めます。
- 詳細データCSVは従来の13列で、実験名・モード・座標・パワー・方向・推奨パワー・速度倍率も含みます。ファイル名は実験名_詳細データ.csv。
- 両CSVはExcelでの日本語読み込みに適したUTF-8 BOM付き、CRLF形式。CSV出力で内部保存データを変更しません。

保存はブラウザ・オリジン単位です。別ブラウザや別URLとは共有されません。保存領域が使えない・容量不足の場合は画面下に表示し、プレイは継続できます。CSVで退避してください。

## CSVの見方

「当たった的」は保存済みの着弾座標と的の範囲から求めます。狙った的と別の的に当たった場合も、その的の名前を出力します。広場・外まわり・場外を含め、どの的にも当たらなければ「的外」です。得点は保存済みの値を使用します。日時は記録時の値（通常ISO 8601のUTC時刻）をそのまま出力します。

## アクセス記録

既存のtower-of-hanoi・lights-outと同じGASアクセスカウンターを共用し、GETのapp=stat-golfで識別します。ページを開くたびに1回だけ送信し、再読み込みは新しいアクセスとして記録します。keepalive:trueを使用し、ゲーム操作・画面切替・保存では送信しません。応答待ち・再試行・カウンター表示はなく、通信失敗でもゲームを継続できます。

ローカルプレビューでも読み込み時に送信します。ブラウザテストは通信を捕捉して実GASへの送信を防ぎます。実際にGASへ送信する場合は、記録が増えることに注意してください。

## バーの速さ

初期設定は「ふつう（70%）」。大砲選択の下で「ゆっくり（50%）」「ふつう（70%）」「はやい（100%）」を選べます。割合は速度選択を追加する前の速さが基準です。パワー・方向の両方に同じ倍率をかけ、大砲ごとの速さの比率を維持します。1回の発射の途中では変更できません。

各発射に speedMultiplier（0.5 / 0.7 / 1）を保存します。記録表に選んだ速度を表示し、詳細データCSVの末尾にも倍率を出力します。通常CSVでは「ゆっくり・ふつう・はやい」で表示します。速度情報がない旧記録は当時の100%に対応する「はやい」として通常CSVに出力し、保存済みデータに後から値を書き足しません。ページを開いたときの選択は「ふつう」です。

## STAT GOLFとの互換性

保存キー `stat-golf-v1`、バージョン1、4つの大砲ID（旧道具ID）、的ID、得点・着弾・操作値の形式を維持しています。同じブラウザ・同じURLで開けば、既存の実験をそのまま呼び出せます。旧実験名は変更しません。旧道具IDは新しい大砲名で表示し、CSVも新しい大砲名で出力します。

得点計算、的の位置・半径、最大飛距離、大砲ごとの基準バー速度、ばらつき、乱数処理、パワー・方向の計算を変更していません。tests/theme.test.js が変更前の数値・固定乱数の着弾を照合し、tests/theme-browser.cjs が旧データの読み込み・統計・CSV・比較を検証します。

## 統計の定義

分散は記録した発射を母集団として `Σ(x−平均)²/n` で計算します。標準偏差はその平方根、0点率は0点の発射数/nです。未試行の統計量は `—` とし、得点0と区別します。ヒストグラムは `[下限, 上限)` の階級。最大150点を必ず含む階級を用意します。

## ゲームモデル

原点から選択した的へ向かう角度に方向値×0.34ラジアンを加算し、飛距離を最大飛距離×パワーとします。2次元の正規乱数で着弾を揺らします。得点は狙った的ではなく実際の着弾で計算します。

シミュレーションの操作誤差は標準偏差eの正規乱数を用い、パワーに `e×大砲速度`、方向に `2e×大砲速度` の誤差を加えます。これは実際の人間の操作を近似する仮定で、技能ごとの優劣を保証するものではありません。結果は [TEST_REPORT.md](TEST_REPORT.md) を参照してください。

## テスト

Node.js 18以降で、追加依存なしに実行できます。

```sh
npm test
npm run simulate
```

ブラウザテストはPlaywrightとGoogle Chrome、起動中のローカルサーバーが必要です。

```sh
npm install --no-save playwright
node tests/browser.cjs
node tests/theme-browser.cjs
node tests/speed-browser.cjs
node tests/access-counter-browser.cjs
node tests/csv-browser.cjs
```

`STAT_GOLF_URL`でプレビューURLを指定できます（ブラウザテストの既定はhttp://127.0.0.1:8000）。

`STAT_GOLF_PLAYWRIGHT` でPlaywrightモジュールのパスを指定できます。`STAT_GOLF_BROWSER` でブラウザチャンネルを指定できます（既定chrome）。

## ファイル

- `index.html` / `style.css`: レスポンシブ画面
- `app.js`: 操作、描画、保存、比較、CSV出力
- `access-counter.js`: ページ読み込み時の共用GASアクセス記録
- `cannon-art.js`: 4種類の大砲のSVG・キャンバス描画
- `speed.js`: 速度選択とバー位置の計算
- `core.js`: 得点・統計・乱数・発射モデル
- `tests/`: 計算テスト、バランスシミュレーション、ブラウザ操作テスト
